# 美美沙龙 · 重做设计文档

目标：画面品质、动画密度、玩法流程和选项丰富度对齐 Bimi Boo Beauty Salon 这一档的学前美容沙龙游戏。
人物、道具、界面全部原创，不复制对方的角色、美术和 UI 资源；对齐的是品类惯例和完成度。

## 0. 现状差距（为什么不在一个水平）

| 维度 | 旧版 | 目标 |
|---|---|---|
| 美术 | 代码手拼 SVG 基本形，无体积、无高光，人物像简笔画 | 专业插画级扁平矢量：同色系深色描边、柔和阴影、高光、材质 |
| 人物 | 一个 Zoey 拼装，表情靠换几条线 | 分层角色：眼睛（睁/眨/闭/笑/惊）、嘴（微笑/大笑/O/嫌弃/委屈）、眉、头发前后层，随操作实时反应 |
| 动效 | 整块平移/缩放/淡入 | 工具有使用动画（剪刀开合、吹风机出风、海绵挤压），角色有呼吸、眨眼、躲闪、痒得扭动；粒子（泡沫、水珠、蒸汽、闪粉）带物理 |
| 流程 | 每房 3–6 步，选项 3–6 个 | 前段“清洁/修复”线性 5–7 步，后段“自由装扮”多页签，每页签 6–12 个选项 |
| 反馈 | 少量 sfx + 星星 | 每一下都有反应：音效、粒子、角色表情、台词；阶段完成有小庆祝；结尾拍照 |

## 1. 总体结构

```
首页 ──「美美沙龙」大门卡 ──> 沙龙大厅（Lobby）
                               ├─ 左：5 张房间卡（可横滑），完成打勾
                               ├─ 右：展台上的当前客人（呼吸、眨眼、点她会笑/挥手）
                               └─ 展台下：换客人 · 放大看 · 拍照 · 重新打扮
房间：SPA 洗脸 / 美发 / 化妆 / 美甲 / 换装
```

- 宠物澡堂（`spa.js`）不属于美容沙龙，移回“照顾小动物”那一组。
- 客人 6 位，每位的妆发、服装跨房间保留（`store.data.salon2.looks[i]`；旧版 `salon` 存档不再读取）。
- 房间通用骨架（与对标一致）：左上 Home、右侧竖排道具栏 + 分类页签、右下（或左下）绿色对勾“完成”。
- 无失败、无计时；线性阶段用“白色虚线圈 + 指引小手 + 只亮下一件工具”引导；自由阶段随时可点对勾结束。
- 完成 = 拍照（闪光 + 相片掉落 + 礼花）→ 回大厅时客人身上带着新造型，房间卡打勾，星星 +1。

### 2.2 主持人

Zoey 只出声音（台词旁白），沙龙房间里不出现扁平小人，避免两种画风混在一起。大厅里也是客人站展台。

## 3. 五个房间

每个房间写：流程 · 每步交互 · 动效 · 台词 · 选项。

台词 key 前缀：`sl-`（新录），已有可复用的标注“复用”。

> 实现说明：Zoey 的声线是英文，所以所有台词按下表的意思写成英文短句录制（`tools/playground/voice-lines.json`，`sl-*` 共 42 句），中文仅作脚本说明。

### 3.1 SPA 洗脸（facial）

开场：客人脸上有泥点 4–6 处、小痘痘 3 个、黑眼圈，表情 sad。台词 `sl-spa-hi`「哎呀，她的小脸脏脏的，我们来帮她洗干净吧！」

| 步 | 工具 | 交互 | 动效 / 反馈 | 台词 |
|---|---|---|---|---|
| 1 洗脸 | 洗面奶瓶 → 海绵 | 拖瓶到脸上挤一坨，再拿海绵来回擦 | 瓶身挤压回弹，奶油挤出拉丝；海绵擦过起泡沫（泡泡数量随擦拭累积、会轻微晃动），泥点随擦拭渐隐；客人 giggle 扭动 | `sl-spa-wash`「挤一点洗面奶，用海绵擦一擦～」 |
| 2 冲水 | 花洒 | 拖花洒扫过泡沫 | 水线粒子 + 溅射水珠；泡沫被冲走滑落；客人 shut | `sl-spa-rinse`「哗啦啦，冲干净啦！」 |
| 3 擦干 | 毛巾 | 拖毛巾轻拍 | 毛巾按压形变，水珠被吸走 | `sl-spa-towel`「用毛巾轻轻擦干。」 |
| 4 痘痘贴 | 痘痘贴（4 款：星星/爱心/小花/云朵） | 选一款，拖到虚线圈里的痘痘上，可贴多个 | 贴上时 squash 动画 + 小闪光；痘痘被盖住后变小消失 | `sl-spa-patch`「把小痘痘贴上可爱的贴纸。」 |
| 5 调面膜 | 碗 + 食材 8 种（草莓、黄瓜、柠檬、牛油果、蓝莓、玫瑰、蜂蜜、燕麦） | 拖 2–4 种进碗，出现勺子后画圈搅拌 | 食材落碗溅起，碗里色块随搅拌旋转融合成混合色，冒小爱心 | `sl-spa-mix`「选几样喜欢的放进碗里，搅一搅！」 |
| 6 敷面膜 | 刷子（蘸碗里的颜色） | 在脸部虚线区内涂抹，覆盖 80% 自动补满 | 笔刷有湿润高光；客人 shut | `sl-spa-mask`「把面膜均匀地刷在脸上。」 |
| 7 黄瓜片 | 黄瓜片 ×2 | 拖到两只眼睛上 | 吸附动画，客人放松地哼一声；背景舒缓音乐，计时 3 s 后小闹钟响 | `sl-spa-relax`「放上黄瓜片，休息一下～」 |
| 8 卸面膜 | 湿棉片 | 擦去面膜 | 面膜卷边剥落，露出发光皮肤（闪光扫过）；客人 love | `sl-spa-glow`「哇，小脸亮晶晶的！」 |
| 9 护肤 | 面霜（4 色：粉/白/绿/金）＋ 棉片 | 点挤面霜、棉片抹匀 | 光泽层渐显 | `sl-spa-cream`「最后抹上香香的面霜。」 |

自由收尾：可再选 **眼罩/发带**（6 款）给客人戴上；对勾 → 拍照。

## 4. 大厅（Lobby）

- 背景：原创沙龙内景（镜台、灯泡化妆镜、植物、彩色瓶罐），柔和渐变+高光。
- 客人展台：呼吸 + 眨眼；点她：随机一个反应（挥手 / 转圈 / 笑出声 + 台词）。
- 换客人：当前客人走下展台（弹跳步伐）→ 新客人走上来挥手；名字气泡。
- 放大：镜头推近到脸（scale 2.1，原点在头部），再点回到全身。
- 拍照：闪光 + 拍立得相片掉落（带当前完整造型），4 s 或点击收起。
- 重新打扮：大海绵扫过，客人恢复初始造型。
- 房间卡：大图标 + 完成打勾；星星 n/5。

## 5. 通用音效与台词

- 音效沿用 `audio.js` 合成音色，新增：`squeeze`（挤瓶）、`snip`（剪刀）、`spray`（喷雾）、`blow`（吹风机循环）、`brush`（刷子沙沙）、`pop-bubble`、`clip`（指甲钳）、`giggle`（笑声，可用 TTS 生成）。
- 台词统一用 Zoey 声线（`tools/playground/voice-lines.json` + Qwen3-TTS），新录约 45 句（见各房间表）。

## 6. 技术方案

### 6.1 选型

| 方案 | 结论 |
|---|---|
| 继续手写 SVG | 否：画不到插画级，是这次差距的根源 |
| PixiJS v8（WebGL） | 否：820 KB 依赖；需要的 MeshRope/滤镜在下面的遮罩方案里用不上 |
| **位图分层 + DOM 变换 + Canvas 遮罩/涂抹** | **采用**：美术用 Codex（gpt-image）生成的插画；角色和道具是叠放的 `<img>`，动画走 WAAPI（GPU 合成）；所有“涂上去 / 擦掉 / 剪掉 / 染色”的东西是 `<canvas>` 图层，用合成模式做遮罩。现有 `Game`（拖拽、rub、toolbox、spray、pointer、win）和无头测试全部沿用 |

### 6.2 美术生产管线

1. **母版**：每类角色先出一张母版（光头半身、手、无头全身），后续所有图层都在母版上“改图”生成。
2. **改图 → 差分抠层**：Codex 以母版为输入改一处（换发型、加头饰、闭眼、穿裙子），`salon-art.py diff` 把改动的像素抠出来成为透明图层，天然与母版对齐。
3. **局部补丁**：表情（闭眼、笑眼、O 嘴…）用 `salon-art.py patch` 取改图的一个矩形、羽化边缘，叠在母版对应位置。
4. **道具表**：同类道具一张图画 6–12 个（网格、互不接触），`salon-art.py slice` 按连通域切成单个文件。
5. **肤色**：只画一个肤色，`salon-art.py skin` 把肤色族像素按明暗比例映射到另外 5 个肤色，所有发型/服装对每位客人都合身。
6. **打包**：`salon-art.py pack` 裁边 + 缩放 + 转 WebP，输出每层在母版坐标里的位置，汇总成 `js/salon/manifest.js`。
7. 生成作业清单在 `tools/playground/salon-art-jobs.json`，`salon-gen.py` 并发调用本地 `codex exec`；原图放 `.salon-art/`（不入库）。

### 6.3 运行时模块（`static/kids-playground/js/salon/`）

| 模块 | 职责 |
|---|---|
| `manifest.js` | 所有图层的文件名与母版坐标（生成） |
| `rig.js` | 角色：`Bust`（半身）、`Hand`、`Body`。图层栈、表情状态机（眨眼、`mood(name, ms)`）、呼吸、`react()`（扭动、缩头、点头） |
| `hair.js` | 发型层：每个发型一张位图 + 剪短遮罩（canvas）+ 卷发遮罩 + 每种染色一张遮罩；`cut(stroke)`、`grow(x)`、`curl(x,y)`、`dye(x,y,col)` |
| `paint.js` | `PaintLayer`：限定区域（遮罩图或多边形）的 canvas，笔刷涂/擦、覆盖率采样、整片填充、渐变/图案笔刷 |
| `props.js` | 道具精灵、工具使用动画（剪刀开合、瓶子挤压、吹风机抖动）、吸附贴纸 |
| `fx.js`（扩展） | 泡沫（会长大、会被戳破）、水流、气流线、闪粉附着、掉落碎发 |
| `ui.js` | 房间骨架：Home、对勾、右侧页签 + 道具栏（可滚动）、虚线引导圈、指引小手 |
| `look.js` | 客人状态（原 `salon.js` 的 look 部分）：发型、发色/染色遮罩快照、妆容、服装、饰品 |

全身像不另画头：运行时把半身的头部合成结果（含发型、妆容）画到全身的脖子上，所以美发和化妆的成果天然出现在换装与大厅里。

### 10.2 美术管线补充

- **Codex（核心图）**：母版、发型、表情、服装、道具表、背景，全部由 `salon-gen.py` 调 `codex exec` 生成（约 120 张）。
- **抠图清理**：生成图的透明通道有雾边和色点。`clean_alpha` 只保留 alpha > 235 的实心主体（开运算、去小连通域），再加 3 px 抗锯齿边。主体内部被阈值打出的小洞（< 120 px）补上，大洞（戒指、手链中间）保持透明。
- **鞋子**：10 条连衣裙改图都自带鞋，`salon-build.py` 在脚踝处（裙摆与鞋之间最后一条空行）切开，鞋子成为独立的一组。
- **全身客人的头**：全身母版自带一个光头，运行时用渐变遮罩把它在下巴下方淡出。半身像（带发型、妆容、贴纸、发饰）缩小 0.7 倍，下巴对齐到全身的下巴，并在下巴下方淡出。这就是 `js/salon/doll.js` 的 `Doll`，换装、大厅、首页大门卡、拍立得都用它。
- **换肤**：`reskin` 先按肤色色度匹配换肤色，再把暖色描边按新旧肤色的亮度比压暗（眼睛区域除外），深肤色客人的轮廓不会泛橙光。
- **本地生成（mflux）**：不复杂的图，或已有参考风格的简单改图，用本地 [mflux](https://github.com/mflux-community/mflux)（Apple Silicon 上的 MLX），省去 Codex 的排队。
  - 模型：**FLUX.2 klein 4B**（Apache-2.0，不需要 HF 授权）。它是 mflux 里最小、带编辑和多参考图的模型，`-q 8` 在 36 GB 的 M3 Pro 上跑得动。
  - 安装：`uv tool install --native-tls --python 3.13 mflux`。
  - 公司网络有 TLS 代理，下载需要先导出系统钥匙串证书，并关掉 Xet 走普通 HTTPS：
    ```sh
    security find-certificate -a -p /Library/Keychains/System.keychain /System/Library/Keychains/SystemRootCertificates.keychain > .salon-art/mflux/ca.pem
    export SSL_CERT_FILE=$PWD/.salon-art/mflux/ca.pem REQUESTS_CA_BUNDLE=$SSL_CERT_FILE HF_HUB_DISABLE_XET=1
    mflux-generate-flux2-edit -m flux2-klein-4b -q 8 --image-paths <参考图> --prompt "<改什么>" --steps 4 --seed 7 --output .salon-art/mflux/<名字>.png
    ```
  - 分工：新角色母版、成套服装、背景这类“核心图”仍交给 Codex；道具换色或换形、图标、给已有道具补一个同风格变体，用 mflux。
  - 实测：模型缓存后，512 px、4 步的一次改图约 24 s，峰值内存 8.8 GB；首次下载约 16 GB。
  - 入库：输出放在 `.salon-art/mflux/`，在 `salon-build.py` 的 `LOCAL` 表里登记。构建时去掉连到边框的白底，打包进 `PROPS`。第一张是美甲店卡片上的粉色甲油（由透明甲油瓶改色）。

### 10.3 第二轮打磨：每个动作都看得见、每件道具都像真的

- **看得见的变化**：剪过的指甲留一圈白色锯齿断口，锉刀磨平；护甲油是一滴油落下、指甲泛出琥珀色光泽；面霜先在脸上留几坨白色霜（盖在五官之上，落到眼睛上她会闭眼），抹开后变成光泽。
- **拟真的道具**：选色用带颜色的瓶子/罐子（甲油瓶、眼影盒、腮红盒、口红、唇彩、睫毛膏、染发剂、闪粉），拖出来的是沾了颜色的刷子或棒。产品图用 `productTint` 按需重染（`room.js` 的 `products()` / `productArt()`）；产品图缺失时用旧道具图加色点。
- **戴上的效果**：戒指拖到哪根手指就戴在那根手指上（`HAND.fingers`：由指甲主轴推出的戴戒位置和指宽），手链拖到手腕（`HAND.wrist`）。有 Codex 画好的“戴上”图时用它；没有时运行时画一个金戒圈 + 宝石、侧看的手链（远端一半藏在手腕后）。
- **换装**：帽子按头型给出宽度、下沿和倾角，戴帽子时藏起头顶的发饰；手持物放在手的下面一层（`held`），手指压在杆、绳、提手上。Codex 的“戴帽子/握着”图到位后自动替换，并用 keep 遮罩藏住被盖住的头发或张开的手指。翅膀、披风在货架上显示完整的一件（`icon-back-*`），不是穿上后被身体挡住的样子。
- **服装杂线**：`no_threads` 在差分遮罩上去掉细线后，再在成品图的 alpha 上跑一遍（补洞会把描边连到衣服上）；水手服有一条较粗的手臂描边，单独用半径 8。
- **拍照**：美甲拍整只手；每个房间重玩时，这个房间改过的部分清空重来（`clearZone`）。

### 10.4 测试

- “look” 用例检查回到大厅后造型保留、房间打勾。
